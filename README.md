# Портфолио Миши Жолудева

Чистая статическая версия сайта для GitHub Pages.

## Локальная проверка

```bash
npm install
npm run dev
```

## Публикация

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
5. Отправьте изменения в ветку `main`. Workflow автоматически соберёт и опубликует сайт.

Сайт настроен с относительными путями, поэтому он работает как в корневом репозитории `username.github.io`, так и по адресу `username.github.io/repository-name/`.

## Что находится в репозитории

- `src/` — React-код страницы, стили и манифест работ;
- `public/` — только используемые hero-ассеты, шрифты, favicon, OG-картинка и оптимизированные работы;
- `.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages.

Исходные PSD/видео, генераторы, бэкапы, локальные логи и служебные файлы в эту версию не включены.
